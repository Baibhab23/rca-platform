2. ANOMALY DETECTION RESULTS
--------------------------------------------------
Three detectors were applied. Z-Score and Isolation Forest both achieved
perfect precision, flagging only the injected fault rows with no false
positives. The LSTM autoencoder detected the peak of the fault but lagged
on onset by roughly six rows and produced three false positives just past
the window edge.

  Detector               Anomalies flagged      Precision on fault rows
  -----------------------------------------------------------------
  Z-Score (threshold 3σ) 11                     100%
  Isolation Forest (5%)  10                     100%
  LSTM Autoencoder       8                      62%

Recommendation: use Z-Score or Isolation Forest for real-time alerting.
Consider tightening the LSTM threshold factor from 2.0 to 1.5 for earlier
onset detection if false-positive tolerance permits.

Pressure and temperature are the genuine fault triggers. Output quality
appears high on this list because it co-varies with the fault, but it is
a downstream symptom rather than a cause.

Granger causality found no statistically significant lagged predictors
(p > 0.05 for all pairs), which confirms the fault is a sudden spike
rather than a slowly building trend.

--------------------------------------------------
The LP optimiser selected the two highest-impact interventions within a
60 % resource budget. Full-budget recommendations follow in parentheses.

  Action 1 — Temperature  [HIGH]
  Effect size: 17.241  |  Expected impact: 16.296  |  Direction: decrease
  Temperature spiked ~20°C above baseline during anomaly window.
  1. Inspect heating/cooling elements and temperature controller PID tuning.
   2. Verify thermocouple calibration — a +20°C drift can indicate sensor fault.
   3. Set control limits at ±5°C from the 75°C setpoint (3-sigma = ±14.7°C observed).
   4. Cross-check with pressure — simultaneous pressure drop + temperature spike often indicates a coolant flow failure.

  Action 2 — Pressure  [CRITICAL]
  Effect size: 5.632  |  Expected impact: 4.783  |  Direction: decrease
  Pressure dropped ~30 bar below baseline during anomaly window.
  1. Check pressure regulator / relief valve for malfunction.
   2. Inspect upstream supply lines for blockage or leak.
   3. Set a real-time alert if pressure deviates > 10 bar from the 100-bar setpoint.
   4. Review maintenance logs for the last 30 days — this type of drop is often preceded by slow valve wear.

  If resources allow (full budget), also address:
